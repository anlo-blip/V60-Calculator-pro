# مِعيار V2 — MIYAR Coffee Recipes

نسخة ويب تجريبية من منصة مِعيار لإنشاء وصفات قهوة xBloom. الكود الموجود في هذا المجلد منفصل عن تطبيق V60 في جذر المستودع.

## تجربة النسخة

- افتح `index.html` في متصفح عادي يدعم JavaScript.
- لعرضها عبر GitHub Pages، افتح **Settings → Pages** في المستودع، واختر **Deploy from a branch → main → /(root)** إن لم يكن Pages مفعلاً بالفعل.
- عند تفعيل GitHub Pages من جذر المستودع، سيكون مسار النسخة المتوقع:
  `https://anlo-blip.github.io/V60-Calculator-pro/miyar-v2/`
- هذا عنوان متوقع فقط، ولا يُعد موقعاً منشوراً أو مختبَراً حتى يؤكَّد تشغيل Pages.

## الوظائف التجريبية

- إنشاء وصفات قهوة اعتماداً على البيانات والتفضيلات.
- إعدادات الصبات وتعديلها والتحقق من كمية الماء.
- مقارنة الوصفات وتقييمها وحفظها محلياً داخل المتصفح.
- واجهة عربية وإنجليزية متجاوبة.

## القيود

- هذا إصدار تجريبي، وليس خدمة إنتاجية.
- التصدير الحقيقي إلى تطبيق xBloom غير موصول.
- قراءة صور أكياس البن بالذكاء الاصطناعي غير مفعلة.
- بيانات الوصفات محفوظة محلياً، ولا توجد مزامنة حسابات بين الأجهزة في هذه النسخة.
- لا تضع أي مفاتيح API أو أسرار في `index.html`.
