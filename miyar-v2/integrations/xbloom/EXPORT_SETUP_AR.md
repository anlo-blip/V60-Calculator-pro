# ربط تصدير وصفات مِعيار إلى xBloom — خطة تنفيذ قابلة للاختبار

**الحالة: غير متصل.** هذا المستند ومحوّل البيانات ليسا تكاملاً حياً، ولا يجوز تمكين زر التصدير لمجرد وجودهما.

## ما الذي ثبت

- GitHub Pages موقع ثابت؛ لا يحتوي على خادم آمن لحفظ بيانات حساب xBloom أو إرسال طلبات كتابة.
- يصرّح rashf.net/about بأنه يستخدم حساب xBloom خاصاً بالموقع وواجهة غير رسمية.
- يوجد مثال MIT مجتمعي: https://github.com/denull0/xbloom-agent يدعم إنشاء وصفات Studio ومشاركة رابطها.
- مشاركة رابط وصفة موجودة في خدمة xBloom تختلف عن تحميل ملف JSON خاص بمِعيار.

## بنية التنفيذ

1. أبقِ واجهة مِعيار العامة على GitHub Pages.
2. أنشئ خدمة خلفية على Vercel أو Supabase Edge Functions، بعد توصيل حساب الاستضافة.
3. أنشئ حساب xBloom مخصصاً للمنصة (لا تستخدم حسابك الشخصي للإنتاج).
4. احفظ جلسة xBloom والتوكن في مخزن أسرار الخدمة أو خزنة مشفرة؛ لا تحفظها في المستودع أو المتصفح، ولا تطلب من المستخدمين كلمات مرور.
5. أضف نقطة POST /api/xbloom/export على الخادم. تتحقق من المدخلات، وتعالج المعدل والإساءة، وتتبع معرف طلب متكرر (idempotency key).
6. حوّل الوصفة بواسطة recipe-mapper.js بعد التحقق من توافق قيم الطحن وباقي حدود الجهاز، ثم استدعِ اتصال xBloom المسموح به.
7. تحقّق من أن حفظ الوصفة نجح وأن رابط المشاركة يعمل بالفعل، ثم أرجع JSON به shareUrl. لا تستخدم معرّفاً مخترعاً.
8. الواجهة تعرض حالة الحفظ وتفتح الرابط الحقيقي فقط بعد النجاح. لا تشغّل الماكينة آلياً.
9. اختبر على آيفون وجهاز xBloom Studio فعليين: الطحن، سرعة الدوران، كل صبة، الصب المركزي/الدائري/الحلزوني، اهتزاز قبل/بعد الصبة، والتوقفات.

## تنبيه: اختلاف مقاييس الطحن

مِعيار حاليًا يعرض 1–80. بينما يوثق xbloom-agent مثالاً لقبول grind_size من 40 إلى 120. ليس هناك تحويل مؤكد بين المقياسين. يتعمّد محوّل البيانات رفض التصدير قبل تزويده بقيمة طحن مثبتة من اختبار الجهاز، ولا يجوز استخدام جمع ثابت أو قيمة افتراضية لتجاوز الرفض.

## عقد بيانات مقترح

POST /api/xbloom/export

Body: { "recipe": <Miyar v2 recipe>, "idempotencyKey": "..." }

نجاح (HTTP 201/200): { "status": "ready", "shareUrl": "https://share-h5.xbloom.com/?id=...", "provider": "xbloom" }

تعذّر مؤقت/لا يوجد تكامل (HTTP 503): { "status": "unavailable", "reason": "xbloom_connector_not_configured" }

الردود النهائية لا تحتوي أبدًا على كلمات مرور أو توكنات جلسة.

## متطلبات التشغيل المتبقية

- خدمة خلفية متصلة قابلة لنشر مفاتيح سرية، وصلاحية نشرها.
- تكامل xBloom مصرح ومختبر أو قبول مخاطر التكامل غير الرسمي بعد مراجعة الشروط.
- إعداد حساب xBloom مخصص في الخادم، دون إرسال بيانات دخوله عبر الدردشة أو تخزينها في GitHub.
- اختبار رابط مشاركة صادر من إنشاء وصفة حقيقية والتحقق من تشغيله في تطبيق الهاتف.
